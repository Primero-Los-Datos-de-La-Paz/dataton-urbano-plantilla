# Catálogo

| Archivo | Contenido |
|---|---|
| `fuentes.csv` | Una fila por fuente de datos: institución, URL, formato, licencia o términos, si se puede redistribuir, cobertura, periodicidad y estado de verificación |
| `fuentes.schema.json` | Reglas para validar `fuentes.csv` |
| `indicadores_*.csv` | Indicadores de cada desafío con su fuente candidata, responsable y brecha |
| `INFORME_FUENTES.md` | Qué se verificó, qué no, licencias dudosas y brechas |

Cada edición llena estos archivos. Todo lo que no se haya comprobado se marca **SIN VERIFICAR**.
