# Reglas de uso

(Para datos públicos, indica aquí la licencia de la fuente. Para datos internos, conserva estas reglas.)

1. Los datos se usan **solo** para los fines del datatón.
2. **No se republican** ni se comparten fuera del equipo.
3. No se intenta identificar personas ni se cruzan datos con ese fin.
4. Si encuentras un posible dato personal: **no lo copies**, avisa de inmediato por el buzón institucional indicando archivo, columna y fila, y sigue `SECURITY.md`.
5. El original de `data/raw/` no se edita. Todo cambio se documenta y se puede reproducir.
6. Ningún resultado se presenta como cifra oficial.
