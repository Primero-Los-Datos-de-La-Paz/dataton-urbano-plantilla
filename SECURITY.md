# Seguridad y datos personales

## Si subiste o encontraste un dato personal

Un dato personal es, por ejemplo, el nombre de una persona, su cédula, teléfono, correo, dirección particular o fecha de nacimiento.

1. **Avisa de inmediato** a la organización por el buzón institucional (abajo). **No abras una incidencia pública** y no copies el dato en el mensaje: indica el archivo, la columna y la fila.
2. **Borrar el archivo no alcanza.** Git guarda el historial: el dato sigue visible en los commits anteriores.
3. La organización:
   - pasa el repositorio a privado si era público;
   - reescribe el historial o recrea el repositorio sin el dato;
   - pide a las áreas jurídica y de tecnología que evalúen el incidente;
   - avisa al responsable del dato.
4. Nadie debe descargar ni reenviar el archivo afectado mientras se resuelve.

## Si encontraste una credencial o un token

No lo uses. Avisa por el buzón con el nombre del archivo. La organización revoca la credencial y limpia el historial.
