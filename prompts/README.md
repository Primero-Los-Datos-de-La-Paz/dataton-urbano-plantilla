# Instrucciones de construcción (prompts)

Esta carpeta guarda las instrucciones con las que se construyen los repositorios de una edición con ayuda de un asistente de programación. Se organizan por fases, cada una con una puerta de revisión humana:

| Fase | Tema |
|---|---|
| P0 | Verificación del entorno y extracción de la convocatoria |
| P1 | Plantilla reutilizable y edición |
| P2 | Catálogo de fuentes |
| P3 | Paquetes de datos |
| P4 | Herramientas y validación |
| P5 | Evaluación y repositorios de equipo |
| P6 | Documentación |
| P7 | Revisión de calidad, ensayo y publicación controlada |

La plantilla no incluye los prompts de ninguna edición concreta, porque contienen datos de esa ciudad. Cada edición guarda los suyos en su propia carpeta `prompts/`.
